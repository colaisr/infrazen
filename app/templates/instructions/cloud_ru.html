Инструкция по подключению Cloud.ru

Пошаговое руководство для интеграции Cloud.ru (Облако.ру) с InfraZen

Требования

  • Активный аккаунт Cloud.ru
  • Доступ к консоли Cloud.ru
  • Права на создание сервисных аккаунтов (роль admin или editor на проект)

1Создание сервисного аккаунта

Сервисный аккаунт необходим для безопасного доступа InfraZen к вашим ресурсам в Cloud.ru.

  1. Откройте консоль Cloud.ru
  2. В боковом меню перейдите в раздел "Пользователи" → "Сервисные аккаунты"

Раздел управления сервисными аккаунтами: Пользователи → Сервисные аккаунты

Форма создания сервисного аккаунта: укажите имя и описание

  1. Нажмите кнопку "Создать аккаунт" (Create Account)

Выбор проекта для сервисного аккаунта

  1. В открывшейся форме укажите имя аккаунта (например, infrazen-integration)

Назначение роли "viewer" или "reader" на проект

  1. Добавьте описание (например, "Сервисный аккаунт для InfraZen FinOps платформы")
  2. Выберите роль из выпадающего списка "Роли на проект" (выберите "Администратор проекта" или другую подходящую роль)

Выберите роль из выпадающего списка "Роли на проект" (например, "Администратор проекта")

  1. Нажмите "Создать"

2Выбор проекта

⚠️ Важно: Сервисный аккаунт может иметь доступ только к одному проекту. Выберите проект, который содержит ресурсы, которые вы хотите отслеживать.

  1. После создания сервисного аккаунта откройте его страницу

Страница созданного сервисного аккаунта

  1. В разделе "Роли на проект" (Roles on Project) выберите проект из выпадающего списка
  1. Примечание: После создания проект нельзя изменить, поэтому выберите правильный проект
Критически важно: Выберите проект, который содержит ресурсы (VM, диски, сети), которые вы хотите отслеживать в InfraZen. После создания сервисного аккаунта проект нельзя изменить.

3Создание ключа доступа

Ключ доступа (Access Key) используется для аутентификации сервисного аккаунта в InfraZen.

  1. На странице сервисного аккаунта перейдите в раздел "Учетные данные доступа" → "Ключи доступа" (Access Credentials → Access Keys)
  2. Нажмите кнопку "Создать ключ" (Create Key)

Диалог создания ключа доступа

  1. В диалоге создания ключа:
    • Укажите описание ключа (например, "InfraZen Integration")
    • Установите срок действия (или выберите "Бессрочно" / Unlimited)
  2. Нажмите "Создать"
  1. Критически важно: После создания ключа сохраните оба значения:
    • Key ID (логин) — это ваш api_key для InfraZen
    • Key Secret (пароль) — это ваш api_secret для InfraZen

Окно с созданными Key ID и Key Secret — сохраните оба значения!

Важно: Key Secret показывается только один раз! Обязательно сохраните его в безопасном месте. Если потеряете секрет, придется создать новый ключ.
Формат ключей: Key ID и Key Secret используются для получения временного токена доступа (access_token) через IAM API Cloud.ru. InfraZen автоматически обновляет токен каждые 50 минут.

4Добавление подключения в InfraZen

  1. Перейдите в раздел "Подключения" в InfraZen
  2. Нажмите кнопку "+ Добавить подключение"
  3. Выберите провайдера "Cloud.ru" из выпадающего списка
  4. Заполните поля:
    • Название подключения: Любое удобное имя (например, "Cloud.ru Production")
    • API Key: Вставьте ваш Key ID из шага 3
    • API Secret: Вставьте ваш Key Secret из шага 3
    • Описание: Опционально, для ваших заметок
  5. Обязательно: Нажмите "Тест подключения" — должна появиться галочка ✅
  6. Если тест успешен, нажмите "Сохранить"
Важно: Всегда тестируйте подключение перед сохранением! Это гарантирует, что Key ID и Key Secret корректные и сервисный аккаунт имеет необходимые права.

Возможные ошибки при тестировании:

  • "invalid_client: client not found" — проверьте, что Key ID и Key Secret скопированы правильно (без лишних пробелов)
  • "Authentication failed" — проверьте, что ключ не истек (если был установлен срок действия)
  • "Permission denied" — сервисный аккаунт не имеет роли viewer или reader на проект
  • "Project not found" — сервисный аккаунт не привязан к проекту или проект был удален

5Синхронизация данных

После сохранения подключения вы можете запустить синхронизацию одним из способов:

Вариант 1: Ручная синхронизация (рекомендуется для первого раза)

  • Синхронизация конкретного провайдера: На карточке подключения нажмите кнопку "Синхронизировать"
  • Полная синхронизация: В разделе "Подключения" нажмите "Синхронизировать все"

Вариант 2: Автоматическая синхронизация

InfraZen автоматически синхронизирует данные каждое утро по расписанию.

Что будет синхронизировано:

  • Виртуальные машины (VMs): полные характеристики (CPU, RAM, диски, IP-адреса), статус, регион
  • Диски (Volumes): все диски, включая привязанные к VM (объединены с VM для удобства)
  • IP-адреса (Networks): прямые IP-адреса, привязанные к VM (объединены с VM)
  • Bare Metal: серверы Bare Metal (если присутствуют в биллинге)
  • Стоимость: реальные затраты из биллинга Cloud.ru (ежедневные и месячные)
Совет: Первая синхронизация занимает 30-60 секунд в зависимости от количества ресурсов. InfraZen использует подход "billing-first" — все ресурсы обнаруживаются из данных биллинга, что гарантирует полное покрытие всех оплачиваемых ресурсов.

Особенности синхронизации Cloud.ru:

  • Объединение ресурсов: Диски и IP-адреса автоматически объединяются с родительскими VM для более удобного отображения
  • Автоматическое определение Project ID: Project ID извлекается из JWT токена автоматически, не требуется указывать вручную
  • Billing-first discovery: Все ресурсы обнаруживаются из данных биллинга, включая те, которые могут быть недоступны через обычные API endpoints

Права доступа и безопасность

Минимальные права для работы InfraZen:

  • viewer или reader на проект — просмотр всех ресурсов в проекте + доступ к данным биллинга

Поддерживаемые уровни назначения прав:

  • Проект (Project): InfraZen увидит только ресурсы в этом проекте — рекомендуется для большинства случаев
Примечание: Сервисный аккаунт Cloud.ru может иметь доступ только к одному проекту. Если у вас несколько проектов, создайте отдельный сервисный аккаунт для каждого проекта.
Безопасность: InfraZen работает в режиме "только чтение" и не может изменять, создавать или удалять ваши ресурсы в Cloud.ru.

Рекомендации по безопасности:

  • ✅ Используйте роли на уровне проекта (не организации), когда это возможно
  • ✅ Используйте роли только для чтения (viewer, reader)
  • ✅ Установите срок действия на ключи доступа (не используйте "Бессрочно")
  • ✅ Регулярно обновляйте ключи (минимум раз в год)
  • ✅ Используйте отдельный сервисный аккаунт для InfraZen (не делите с другими инструментами)
  • ✅ Мониторьте использование сервисного аккаунта в консоли Cloud.ru

Решение проблем

Подключение не проходит тест:

  1. Убедитесь, что Key ID и Key Secret скопированы правильно (без лишних пробелов в начале или конце)
  2. Проверьте, что сервисный аккаунт имеет роль viewer или reader на проект
  3. Убедитесь, что роль назначена на нужный проект
  4. Проверьте, что ключ доступа не истек (если был установлен срок действия)
  5. Убедитесь, что сервисный аккаунт активен в консоли Cloud.ru

Синхронизация не находит ресурсы:

  1. Проверьте, что ресурсы находятся в том же проекте, на который назначена роль
  2. Убедитесь, что у сервисного аккаунта есть доступ к данным биллинга (может потребоваться роль billing.viewer)
  3. Проверьте права сервисного аккаунта в консоли Cloud.ru
  4. Убедитесь, что в проекте есть ресурсы (VM, диски, сети)

Не отображается стоимость ресурсов:

  1. Убедитесь, что у сервисного аккаунта есть доступ к данным биллинга (роль billing.viewer или viewer на проект)
  2. Проверьте, что ресурсы имеют стоимость в биллинге Cloud.ru (бесплатные ресурсы показывают стоимость 0)
  3. Запустите синхронизацию повторно через несколько часов (данные биллинга могут обновляться с задержкой)
